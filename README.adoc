= Ammitto UN sanctions data

image:https://github.com/ammitto/data-un/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-un/actions/workflows/fetch.yml"]

This repository stores the United Nations Security Council Consolidated List
as YAML for Ammitto. `processed/` holds one file per listed
individual or entity.

== Source

* Publisher: United Nations Security Council
* List page: https://main.un.org/securitycouncil/content/un-sc-consolidated-list
* File downloaded (XML): https://scsanctions.un.org/resources/xml/en/consolidated.xml

The Consolidated List includes all individuals and entities subject to
measures imposed by the Security Council. Each sanctions committee publishes
the specific measures that apply to the names listed in relation to it.

== Contents

`processed/` holds one file per listing, named after its UN reference number
in lower case: `processed/qdi-001.yaml` is `QDi.001`. A few references carry a
trailing space in the UN XML, which shows in the file name (`kpe-023-.yaml`). In the reference, `i`
marks an individual and `e` an entity.

`processed/_index.yaml` lists every file, with the time of the last fetch.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `reference_number` | string | UN reference number, such as `QDi.001`
| `dataid`, `versionnum` | string | Identifier and version of the entry in the UN XML
| `un_list_type` | string | The sanctions regime, such as `Al-Qaida`, `Taliban`, `DPRK` or `Iran`
| `listed_on` | string | Listing date, `YYYY-MM-DD`; a few values carry a time-zone offset, such as `2015-07-01-04:00`
| `first_name` | string | Individuals: first name; entities: the name
| `second_name`, `third_name`, `fourth_name` | string | Individuals: further name parts
| `aliases` | list or null | `alias_name` and `quality` (such as `Good`, `Low` or `a.k.a.`)
| `gender` | string | Individuals: `Male` or `Female`, where given
| `designations` | list | Individuals: designations, under `values`
| `nationalities` | list | Individuals: nationality, under `value`
| `date_of_birth` | map | Individuals: `type_of_date` (`EXACT`, `APPROXIMATELY` or `BETWEEN`), with `date` or `year` where given
| `place_of_birth` | map | Individuals: `city`, `state_province`, `country`
| `documents` | list or null | Individuals: identity documents, `type_of_document`, `number`, `issuing_country`, `note`
| `addresses` | list or null | `street`, `city`, `state_province`, `country`, `note`
| `comments1` | string | Further information published with the listing
|===

`downloaded/un-data.xml` is an empty file and `update.log` an older
log; the daily fetch updates neither.

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/*.yaml").sort.each do |path|
  next if File.basename(path) == "_index.yaml"

  record = YAML.safe_load_file(path)
  name = record.values_at("first_name", "second_name", "third_name", "fourth_name").compact.join(" ")
  puts [record["reference_number"], record["un_list_type"], name].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import os
import yaml

for path in sorted(glob.glob("processed/*.yaml")):
    if os.path.basename(path) == "_index.yaml":
        continue
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    parts = ("first_name", "second_name", "third_name", "fourth_name")
    name = " ".join(record[p] for p in parts if record.get(p))
    print(record["reference_number"], record["un_list_type"], name, sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/un.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 06:30 UTC and commits any change to `processed/`. It runs with
`--prune`, so a listing the Security Council has removed is deleted here on
the next fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.3 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch un --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/un[`lib/ammitto/sources/un/`].
Report data or source-list issues in
https://github.com/ammitto/data-un/issues[this repository].
